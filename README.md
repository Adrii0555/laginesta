# La Ginesta 🌿

Aplicación móvil y plataforma web para la gestión de pedidos y digitalización del bar de **La Ginesta** (Santa Susanna).

Este proyecto tiene como objetivo principal optimizar el flujo de trabajo del personal del bar y mejorar la experiencia de los clientes, permitiendo realizar y gestionar comandas de forma ágil, intuitiva y en tiempo real desde cualquier dispositivo.
